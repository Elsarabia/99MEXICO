## Cómo cambiar algo

Todo lo que se personaliza está marcado dentro de `index.html` con un comentario
`<!-- 99: ... -->`. Busca ese texto y vas a encontrar cada punto editable: WhatsApp,
dirección, horarios, profesores, seminarios, link de pago.

Para editar desde el navegador: abre el archivo en GitHub, ícono del lápiz,
cambia lo que necesites y **Commit changes**. El sitio se actualiza en 1–2 minutos.

## Imágenes por subir

Se suben a la raíz del repositorio (botón **Add file → Upload files**) con estos nombres:

- `logo.png` — logo con fondo transparente, mínimo 1000×1000 px
- `og.jpg` — 1200×630 px, es la imagen que aparece al compartir el link por WhatsApp
- `victor-hugo.jpg`, `joaquin.jpg`, `orlando.jpg` — profesores, verticales 4:5

En el código ya está la línea `<img>` comentada para cada foto de profesor.
